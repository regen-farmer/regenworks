# Security Policy

## Reporting A Vulnerability

Please report suspected vulnerabilities privately. Use GitHub private vulnerability reporting if it is enabled for this repository. If it is not available, contact the maintainers directly at `hello@regenworks.com`.

Do not open public issues for active vulnerabilities, leaked credentials, authentication bypasses, or data exposure reports.

## Supported Versions

Until a public release policy is defined, security fixes are handled on the active `dev` and `main` branches.
